# LOBB brand assets

- `logo/` contains light, dark, mark, wordmark, and lockup assets.
- `icons/` contains favicon and install-icon assets.
- `badges/` contains product trust badges.

Use [docs/DESIGN.md](../docs/DESIGN.md) for usage rules and visual tokens.

## Placement rules

- Use the mark from 16px to 40px. Use a wordmark or lockup above 40px.
- Maintain clear space equal to the mark's ball diameter on every side.
- Use the dark wordmark on warm surfaces and the white wordmark on charcoal surfaces.
- Distributed SVG logo assets use paths only; no external fonts are required.
